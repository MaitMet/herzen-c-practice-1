# Практическая работа №1 — циклы, условия, массивы (C)

**Отчёт:** [lab_1-Владимиров_Савелий_1_1об_ПОО-2.md](lab_1-Владимиров_Савелий_1_1об_ПОО-2.md) — постановка задач, математические модели, идентификаторы, код и результаты (скриншоты в `screenshots/`).

Выполненные задания (разделы «Марс» и «Численное интегрирование» не входят):

| Файл | Задание |
|---|---|
| `01_padovan.c` | Числа Падована, не превосходящие `m` |
| `02_digit_sum.c` | Сумма цифр положительного числа |
| `03_arrays_task1.c` | Массивы, задача 1: `y = x²`, среднее, сколько больше среднего |
| `04_arrays_task2.c` | Массивы, задача 2: обратный порядок элементов |
| `05_arrays_task3.c` | Массивы, задача 3: транспонирование матрицы 3×3 |
| `06_arrays_task4.c` | Массивы, задача 4: сортировка вставками внутри `main` |
| `07_arrays_task5.c` | Массивы, задача 5: палиндром и второй по величине элемент |

## Сборка и запуск

```bash
gcc -Wall -Wextra -std=c11 01_padovan.c -o padovan && ./padovan
```

Любой другой файл собирается так же.
